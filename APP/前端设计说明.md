# 食库管家 · 前端设计说明文档

> 版本：v1.0 · 主题：**暖意厨房（Warm Kitchen）**
> 适用范围：食库管家移动端（Vue 3 + Vant 4）全部 12 个页面
> 设计目标：以「食物 / 食谱 / 冰箱」三元素为核心，构建低饱和、自然和谐、统一识别的视觉体系

---

## 一、设计理念

### 1.1 核心主题
食库管家是「家庭冰箱食材进销存 + 智能配菜」应用。本次视觉重构围绕三大元素展开：

| 元素 | 视觉表达 | 对应色 |
|------|---------|--------|
| 🥬 **食物** | 食材的新鲜与品类，通过分类专属底色一眼可辨 | 鼠尾草绿、暖玫瑰、雾霾蓝、暖驼、冰灰蓝 |
| 🍳 **食谱** | 烹饪温度与食材到菜的转化，暖点缀色承载 | 赤陶橙 |
| ❄️ **冰箱** | 冷鲜储藏的清凉感，冷点缀色承载 | 雾霾蓝 |

### 1.2 设计原则
1. **低饱和优先**：所有颜色避开 Vant 默认高饱和值（`#07c160`/`#ee0a24`/`#ff976a`），改用莫兰迪化的自然色，长时间观看不刺眼。
2. **色调统一**：全局通过 CSS 变量 + Vant 主题覆写，确保导航栏、Tabbar、按钮、单元格、弹层等组件自动融入主题，零割裂。
3. **语义驱动**：颜色不单纯装饰，而是承载「新鲜→临期→过期」的渐进语义，让用户凭颜色即可判断状态。
4. **功能零损耗**：所有按钮、表单、弹层、路由、store 逻辑保持原样，仅视觉层重构。

## 三、食材分类专属底色系统

为 5 类食材设计取自食材本身视觉联想的专属底色，通过卡片左侧 4px 色条 + 浅底实现「一眼可辨」。色值定义于 `src/utils/index.js` 的 `getCategoryColors(category)`。

| 分类 value | 中文标签 | 卡片浅底 | 色条 / 圆点 | 视觉联想 |
|-----------|---------|---------|------------|---------|
| `vegetable` | 蔬菜 | `#EDF1E8` | `#7C9473` 鼠尾草绿 | 🥬 叶菜 |
| `meat` | 肉禽蛋奶 | `#F5E6E2` | `#C97B6E` 暖玫瑰 | 🥩 鲜肉 |
| `seafood` | 水产 | `#E8EEF4` | `#6E8CA8` 雾霾蓝 | 🐟 水域 |
| `dried` | 干货调料 | `#F0E9DC` | `#A88B6A` 暖驼 | 🌾 谷物香料 |
| `frozen` | 速冻食品 | `#E9EEF1` | `#8BA0B0` 冰灰蓝 | 🧊 冷冻 |

**实现**：所有食材卡片（库存清单、临期预警、出库、报表明细）通过 `<template #icon>` 注入 `<span class="cat-bar" :style="{ background: getCategoryColors(food.category).dot }">`，渲染于卡片左侧绝对定位。

## 四、临期食品醒目提醒机制

采用「颜色 + 图标 + 位置优先 + 动效」四重组合，确保临期食材在视觉上无法被忽略。

### 4.1 颜色预警
- 临期（≤7天）：卡片底色变 `--sk-warn-bg` 蜜糖琥珀，剩余天数文字变 `--sk-warn` 琥珀色加粗。
- 即将过期（≤2天）：卡片底色变 `--sk-danger-bg` 砖红浅底，剩余天数文字变 `--sk-danger` 砖红加粗。
- 已过期：卡片底色变 `--sk-expired-bg` 暖灰，整体 `opacity: 0.82` 置灰弱化。

### 4.2 图标 / 状态点提示
卡片标题右侧注入 `.sk-status-dot` 状态圆点：
- 即将过期：`.danger` 砖红圆点 + **呼吸脉冲动画**
- 临期：`.warn` 琥珀圆点
- 已过期：`.expired` 暖灰圆点
- 正常：`.fresh` 鼠尾草绿圆点（仅出库/库存页显示）

### 4.3 位置优先级
沿用 `src/stores/inventory.js` 的 `sortedFoods` 计算属性：按 `expired → red → yellow → green` 升序、同状态内按剩余天数升序排列。首页「临期提醒」取前 5 条，临期食材天然排在最前。

### 4.4 呼吸动画实现
定义于 `src/styles/theme.css`：

```css
@keyframes sk-pulse {
  0%   { box-shadow: 0 0 0 0 rgba(199, 93, 77, 0.55); }
  70%  { box-shadow: 0 0 0 7px rgba(199, 93, 77, 0); }
  100% { box-shadow: 0 0 0 0 rgba(199, 93, 77, 0); }
}
.sk-status-dot.danger {
  background: var(--sk-danger);
  animation: sk-pulse 1.6s infinite;
}
```

## 五、元素布局说明

### 5.1 全局布局
- **页面根容器**：统一 `var(--sk-bg)` 暖奶油底，留白 `padding: 16px`。
- **卡片**：圆角 14px、`var(--sk-card)` 暖白底、`box-shadow: 0 2px 8px rgba(61,53,46,0.04)` 极浅暖影、左侧 4px 分类/类型色条（绝对定位）。
- **区块标题**：左侧 4px 主色竖条 + 暖深棕文字，font-weight 600。
- **主按钮**：圆角 999px（pill），投影 `0 6px 16px rgba(124,148,115,0.28)` 营造悬浮感。
- **文字层级**：标题 `--sk-text` → 次文 `--sk-text-2` → 辅助 `--sk-text-3`，三级清晰。

### 5.2 各页布局要点

| 页面 | 关键视觉 |
|------|---------|
| **首页 Home** | 130px 高 Hero 卡：主色→冷点缀渐变（食物→冰箱），右上 ❄ 装饰；统计宫格暖白卡；临期卡 2 列紧凑网格 |
| **库存清单 Inventory** | 搜索栏/筛选 Tab 暖白底；食材卡 **2 列紧凑网格**，左条=分类色，临期状态覆盖底色 |
| **临期预警 Expiring** | 顶部 3 统计卡（砖红/琥珀/暖灰语义底+描边）；食材卡 **2 列紧凑网格**强化临期视觉；过期卡置灰+报废按钮 |
| **AI 菜谱 Recipes** | 菜谱卡左条随类型变色（快手→绿/轻食→蓝/正餐→橙）；「冰箱已有」食材按 `daysLeft` 染临期色；详情弹层分区卡+步骤序号主色圆 |
| **数据报表 Reports** | 4 统计卡图标块用语义浅底；分类条形图用新分类色；库存明细 **2 列紧凑网格**（名称居中放大+数量·价格强调+分类） |
| **食材出库 Outbound** | 食材卡左条分类色+临期覆盖；底部固定提交栏暖白底 |
| **出库日志 Logs** | 日志卡左条=出库类型色（烹饪绿/报废红/清零琥珀）；图标圆角块同色浅底 |
| **入库/编辑 AddFood/EditFood** | 表单卡暖白圆角；主按钮主色投影 |
| **偏好/设置/采购 Preferences/Settings/ShoppingPlan** | 统一暖底、卡片圆角、分区标题竖条（采购页用暖点缀色竖条） |

### 5.3 紧凑食材卡网格系统（v1.1 新增）

为提升信息密度与浏览效率，首页/库存/临期/报表明细的食材卡由「占满整行」改为 **2 列紧凑网格卡**，全局共享样式定义于 `src/styles/theme.css` 的 `.sk-food-grid` / `.sk-food-card`，展示数据由 `src/utils/index.js` 的 `getFoodCardMeta(food, categoryLabel)` 统一生成。

**卡片结构（居中布局、主内容放大强调）：**

```
┌────────────────┐
│  ● 剩 2 天      │  ← 顶部：状态点 + 剩余天数（居中、状态色强调）
│                │
│     番 茄       │  ← 主内容：食材名称（18px / 700 / 居中，视觉重心）
│                │
│  3个 · 蔬菜     │  ← 底部：数量 · 分类（居中，数量加粗强调）
└────────────────┘
   ▲ 左侧 4px 分类专属色条（贯穿卡片高度）
```

**排版规范：**
| 元素 | 字号 | 字重 | 颜色 | 对齐 |
|------|------|------|------|------|
| 剩余天数 | 13px | 600 | 状态语义色 | 居中 |
| 食材名称（主内容） | 18px | 700 | `--sk-text` | 居中 |
| 数量 | 13px | 700 | `--sk-text` | 居中 |
| 分类 | 12px | 400 | `--sk-text-2` | 居中 |

**关键实现：**
- `grid-template-columns: repeat(2, 1fr)` + `gap: 10px`，单卡不占满行
- 卡片 `:active` 缩放 0.97 轻反馈，过渡 0.15s
- 状态色覆盖：`.red/.yellow/.expired` 改写卡片底色与天数文字色
- 报表卡复用同一外壳，内层改为「名称 → 数量·价格 → 分类」，价格用 `--sk-accent` 赤陶橙强调
- 所有交互（点击跳转编辑、报废处理）保持不变

## 六、交互逻辑说明

> 本次重构**未改动任何交互逻辑**，仅替换视觉色值与增加展示型绑定。以下为既有逻辑的视觉映射说明。

### 6.1 状态判定链路（保持不变）
```
food.expiryDate
  → utils.calculateRemainingDays(expiryDate)   返回剩余天数
  → utils.getExpiryStatus(remaining)            返回 'green'|'yellow'|'red'|'expired'|'normal'
  → 视觉映射：getExpiryStatusColor / getExpiryStatusLabel / getExpiryVisual（新增）
```

### 6.2 视觉绑定（新增，仅展示型）
- `:class="getExpiryStatus(...)"` → 触发 `.red / .yellow / .expired` 卡片底色
- `:style="{ background: getCategoryColors(food.category).dot }"` → 注入分类色条
- `:class="urgentDotClass(food)"` → 注入 `.sk-status-dot.danger/warn/expired/fresh`
- 菜谱 `getRecipeTagColor(type)` 重映射：`quick→#7C9473`、`healthy→#6E8CA8`、`home→#C97B5C`
- 出库日志 `getLogColor(type)` 重映射：`cook→#7C9473`、`discard→#C75D4D`、`clear→#D4A55B`

### 6.3 功能完整性清单（全部保留）
✅ 入库/编辑/删除食材 ✅ 烹饪出库/变质报废/存量清零 ✅ AI 菜谱生成 + 降级兜底 ✅ AI 设置（API Key 校验/测试连接/显隐切换）✅ 口味偏好 ✅ 临期汇总 ✅ 出库日志 ✅ 数据导出 JSON/CSV ✅ 数据备份/恢复/重置 ✅ 采购计划生成/导出
