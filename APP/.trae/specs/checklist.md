# 食库管家 —— 验收标准清单

## 一、核心功能验收（必须通过）

### 模块 1：食材台账管理模块

- [ ] **F1.1 手动标准化入库**：完整填写6个必填字段（名称、分类、数量、采购日期、保质期、存放分区）后提交，数据正确写入库存表，首页总量实时+1
- [ ] **F1.2 默认保质期自动填充**：选择食材分类+名称后自动填充建议保质期，支持手动修改
- [ ] **F1.3 拍照辅助存档**：允许上传食材外包装/购物小票照片，照片仅关联存储
- [ ] **F1.4 全局库存清单**：以列表/卡片形式展示全部在库食材，支持分类/分区筛选、名称搜索、保质期排序
- [ ] **F1.5 食材信息编辑**：支持修改存量、保质期、存放分区等字段，修改后实时刷新库存表
- [ ] **F1.6 库存总量统计**：首页展示当前在库食材总品类数、总件数、临期预警数

### 模块 1：异常流程验收

- [ ] **F1-E1 必填字段缺失**：提交时必填项未填，前端实时标红提示，阻止提交
- [ ] **F1-E2 重复食材入库**：已存在同名同分类同分区食材时，弹出确认对话框选择合并/新建
- [ ] **F1-E3 保质期输入非法**：采购日期晚于当前日期或保质期为0/负数时，拦截提交并提示
- [ ] **F1-E4 照片上传失败**：文件>5MB或格式不支持时，提示压缩/更换格式，允许跳过
- [ ] **F1-E5 库存数据异常**：存量为负数时自动标记异常状态，提示核对出库记录

### 模块 2：出库消耗管理模块

- [ ] **F2.1 烹饪消耗出库**：勾选多个食材填写消耗数量，校验库存充足后扣减余量，支持批量提交
- [ ] **F2.2 变质报废出库**：选择报废原因（过期变质/储存不当/其他），标记浪费并扣减库存
- [ ] **F2.3 存量清零出库**：一键将食材库存归零，弹出二次确认弹窗
- [ ] **F2.4 出库流水日志**：每笔出库自动生成流水记录，包含类型、食材、数量、时间、剩余库存
- [ ] **F2.5 出库库存不足拦截**：消耗数量大于当前库存时，拦截并提示"库存不足，当前余量为X"

### 模块 2：异常流程验收

- [ ] **F2-E1 出库数量大于库存**：消耗量>余量时，按钮置灰并弹出提示，禁止超额出库
- [ ] **F2-E2 未选择食材即提交**：无食材被勾选时，提交按钮置灰，提示"请至少选择一项食材"
- [ ] **F2-E3 批量出库部分失败**：任一食材库存不足时整单回滚，提示调整后重新提交
- [ ] **F2-E4 误操作撤销**：出库提交后10秒内显示"撤销"按钮，点击可恢复库存与流水
- [ ] **F2-E5 报废食材已为零**：库存为0的食材执行报废时，提示"该食材已无库存，无需报废"

### 模块 3：临期预警模块

- [ ] **F3.1 保质期自动核算**：每日自动计算剩余保质期天数=截止日期-当前日期
- [ ] **F3.2 三色分级标签**：绿色(>7天)、黄色(3~7天)、红色(≤2天)，以色块/标签展示
- [ ] **F3.3 临期推送提醒**：黄色/红色食材进入系统时生成首页提醒卡片；红色触发弹窗提醒
- [ ] **F3.4 临期食材汇总页**：独立页面汇总全部黄色+红色食材，按剩余天数升序排列，顶部显示总数
- [ ] **F3.5 已过期食材标记**：剩余保质期<0的食材自动标记为"已过期"，置顶展示

### 模块 3：异常流程验收

- [ ] **F3-E1 系统日期被篡改**：检测到日期异常回溯时，以最后正常巡检日期为基准计算
- [ ] **F3-E2 保质期截止日期为空**：缺失保质期数据时标记"数据不完整"，提醒补录
- [ ] **F3-E3 提醒频繁打扰**：同一食材红色提醒每日最多弹窗1次，可手动标记"已处理"

### 模块 4：AI 菜谱推荐模块

- [ ] **F4.1 实时库存读取**：AI自动读取当前在库全部食材清单作为输入
- [ ] **F4.2 可用食材筛选**：剔除库存为0或已过期食材，筛选有效食材池
- [ ] **F4.3 三档位菜谱生成**：生成快手懒人餐(5-15分钟)、减脂轻食餐、家常正餐硬菜
- [ ] **F4.4 缺料清单标注**：每道菜谱自动标注所需缺失辅料，汇总为"缺材清单"
- [ ] **F4.5 菜谱详情展示**：展示菜名、烹饪时长、难度、食材清单、热量、步骤概述
- [ ] **F4.6 红色食材优先推荐**：存在红色等级食材时，优先推荐包含该食材的菜谱

### 模块 4：异常流程验收

- [ ] **F4-E1 库存为空/极少**：有效食材<3种时，返回"库存不足，无法生成菜谱"提示
- [ ] **F4-E2 AI生成超时/失败**：推理超过15秒未返回结果，显示"菜谱生成中，请稍候..."
- [ ] **F4-E3 生成菜谱与库存不匹配**：非在库食材必须在"缺失辅料"中明确标出
- [ ] **F4-E4 用户口味偏好缺失**：未录入口味偏好时，按通用家常口味生成菜谱

### 模块 5：智能采购规划模块

- [ ] **F5.1 饮食偏好录入**：录入家庭成员口味偏好（忌口、偏好菜系、辣度），支持修改
- [ ] **F5.2 一周膳食规划**：AI结合库存+口味偏好，生成未来7天每日三餐食谱+采购清单
- [ ] **F5.3 采购清单去重**：自动排除已充足库存食材，仅输出需补缺的食材及建议采购量
- [ ] **F5.4 商超比价参考**：展示主流商超市场参考均价，标注性价比建议

### 模块 5：异常流程验收

- [ ] **F5-E1 用户未录入偏好**：允许直接生成通用版一周规划，口味偏好非必填
- [ ] **F5-E2 比价数据缺失**：某食材无价格数据时显示"暂无数据"占位
- [ ] **F5-E3 规划与库存变动冲突**：库存大量消耗/新增后，提示"库存已变动，建议重新生成"

### 模块 6：数据统计报表模块

- [ ] **F6.1 月度采购支出统计**：自动汇总当月全部入库食材采购金额
- [ ] **F6.2 食材浪费分析**：统计当月变质报废数量、成本、浪费占比，以饼图/柱状图展示
- [ ] **F6.3 高频菜式排行**：基于消耗出库记录，统计当月高频使用食材组合Top5
- [ ] **F6.4 浪费趋势对比**：查看近3个月浪费金额/数量趋势折线图

### 模块 6：异常流程验收

- [ ] **F6-E1 用户未录入采购金额**：允许入库时不填金额，该条目不纳入支出统计
- [ ] **F6-E2 跨月数据为空**：新用户首月无历史数据时，展示空状态插图与引导文案

### 模块 7：系统管理模块

- [ ] **F7.1 定时巡检逻辑**：每日08:00自动遍历食材保质期，重新计算剩余天数并更新预警等级
- [ ] **F7.2 数据本地持久化**：所有数据存储于LocalStorage/IndexedDB，刷新页面不丢失
- [ ] **F7.3 数据导出**：支持导出库存表、出入库流水为CSV/JSON格式
- [ ] **F7.4 数据初始化/清空**：提供"重置所有数据"功能，二次确认后清空全部本地数据

### 模块 7：异常流程验收

- [ ] **F7-E1 浏览器存储空间不足**：LocalStorage超过容量限制时，提示导出备份后清理
- [ ] **F7-E2 数据损坏/解析失败**：检测到数据异常时，提供"恢复最近备份"或"重置数据"选项
- [ ] **F7-E3 用户误触重置**：重置数据操作必须输入确认文字并二次弹窗确认

## 二、数据准确性验收

- [ ] **库存一致性**：执行10次出入库操作后，库存余量=初始值+总入库-总出库，误差为0
- [ ] **预警准确性**：50条测试数据中，三色预警等级判定准确率100%，无漏标/错标
- [ ] **报表准确性**：月度报表总支出=各入库金额之和；浪费金额=各报废出库金额之和

## 三、用户体验验收

- [ ] **移动端适配**：iPhone SE(375px)与iPhone 14 Pro Max(430px)上无横向滚动条
- [ ] **按钮触控区域**：核心按钮触控区域≥44×44px，可单手指触控
- [ ] **字体大小**：字体大小≥14px，清晰可读
- [ ] **操作流程**：完成一次入库≤30秒；完成一次出库≤20秒
- [ ] **异常提示**：所有异常场景有中文友好提示，无技术错误代码，无空白崩溃页

---

## 四、性能与可靠性验收

- [ ] **首屏加载**：首屏加载时间≤2秒（本地运行）
- [ ] **操作响应**：库存100条以内操作响应≤300ms
- [ ] **数据原子性**：出库扣减与流水记录同时成功或同时失败
- [ ] **每日备份**：每日自动备份库存快照
- [ ] **离线可用性**：断开网络后，入库/出库/查询/预警功能正常运行
