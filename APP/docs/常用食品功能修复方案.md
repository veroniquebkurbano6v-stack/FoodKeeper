# 常用食品功能问题修复方案

## 问题诊断报告

### 一、问题现象
用户添加食材成功后，点击"添加为常用食品"时提示失败。

### 二、排查结果

#### 1. 前端检查 ✅
- **表单验证逻辑**：正常，所有必填字段验证完整
- **API请求配置**：正确，请求路径 `/api/favorite/add`
- **提交数据格式**：符合DTO定义，包含name、categoryId、unit、storageZone、defaultExpiryDays

#### 2. 后端检查 ✅
- **Controller定义**：FavoriteFoodController.java 存在，路径正确
- **DTO定义**：FavoriteFoodAddDTO.java 字段完整，注解正确
- **编译产物**：FavoriteFoodController.class 存在于 target/classes 目录

#### 3. 运行时检查 ❌ **发现问题**
- **后端日志错误**：
  ```
  org.springframework.web.servlet.resource.NoResourceFoundException: 
  No static resource api/favorite/add.
  ```
- **根本原因**：FavoriteFoodController未被Spring Boot正确加载和注册
- **表现**：请求被映射到ResourceHttpRequestHandler（静态资源处理器），而不是Controller

#### 4. 数据库检查 ⚠️ **可能问题**
- favorite_food表可能未创建，会导致后续数据库操作失败

### 三、根本原因分析

1. **jar包过时**：运行的是旧版本jar包，未包含FavoriteFoodController
2. **Spring Boot扫描问题**：组件扫描或依赖注入配置异常
3. **编译时机问题**：新增代码后未重新编译打包

## 修复步骤

### 步骤1：重新编译后端项目

**方法A：使用IDE重新运行（推荐）**

1. 在IDE中打开项目：`c:\Users\H1314\Desktop\TRAE食库管家\APP\backend`
2. 找到主类：`com.food.FoodInventoryApplication`
3. 停止当前运行的进程（如果有）
4. **重新编译**：
   - IntelliJ IDEA：Build → Rebuild Project
   - VS Code：Terminal → Run Build Task
5. **重新运行**：点击Debug或Run按钮启动FoodInventoryApplication

**方法B：使用命令行（需要Maven）**
```bash
cd backend
mvn clean package -DskipTests
java -jar target/food-inventory-manager.jar
```

### 步骤2：创建数据库表

**必须执行此SQL，否则常用食品功能无法使用**

执行以下SQL脚本（已保存在 `scripts/create_favorite_food.sql`）：

```sql
USE food_inventory;

CREATE TABLE IF NOT EXISTS `favorite_food` (
    `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `name` VARCHAR(50) NOT NULL COMMENT '食材名称',
    `category_id` BIGINT NOT NULL COMMENT '分类ID',
    `unit` VARCHAR(20) NOT NULL COMMENT '单位',
    `storage_zone` VARCHAR(20) NOT NULL COMMENT '存放分区：refrigerator冷藏室 freezer冷冻层 room常温',
    `default_expiry_days` INT DEFAULT NULL COMMENT '默认保质期天数',
    `default_price` DECIMAL(18, 2) DEFAULT NULL COMMENT '默认单价',
    `use_count` INT NOT NULL DEFAULT 1 COMMENT '使用次数',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '删除标记：0未删除 1已删除',
    PRIMARY KEY (`id`),
    INDEX `idx_user_id` (`user_id`),
    INDEX `idx_category_id` (`category_id`),
    INDEX `idx_use_count` (`use_count`),
    UNIQUE KEY `uk_user_name` (`user_id`, `name`, `deleted`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='常用食品表';

-- 验证表创建成功
SHOW CREATE TABLE favorite_food;
```

### 步骤3：重启前端服务（如果需要）

前端服务应已在运行中，如果没有运行：

```bash
cd frontend
npm run dev
```

访问地址：http://localhost:5173/ 或 http://localhost:5174/

## 如果问题仍然存在

### 检查清单：

1. **确认IDE重新编译**
   - 检查target/classes目录中FavoriteFoodController.class的修改时间
   - 应为最新编译时间

2. **确认Spring Boot正确启动**
   - 后端启动日志应显示：`Mapped 23 mappings in 'requestMappingHandlerMapping'`
   - 应包含FavoriteFoodController的映射

3. **确认数据库连接**
   - 后端日志应显示：`HikariPool - Start completed`
   - SQL执行应成功

4. **确认表已创建**
   - 在MySQL中执行：`SHOW TABLES LIKE 'favorite_food';`
   - 应返回：favorite_food

5. **检查网络请求**
   - 浏览器F12 → Network标签
   - 查看 `/api/favorite/add` 请求
   - Status应为200，Response应为：`{code: 200, message: "操作成功", data: ...}`
